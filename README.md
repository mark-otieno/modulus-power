# Modulus Power website shell

A responsive website for **Modulus Power and Electrical Controls Limited**, using the navy and orange palette and logo from the supplied business card. It presents:

- Industrial and domestic electrical installation
- Solar installation and maintenance
- Refrigeration and air conditioning
- CCTV and electric fencing
- Electrical sales

The home page links to `products.html`, a filterable catalog with 59 product examples. Web-sized catalog images are in `images/catalog/`; cleaned crops of the WhatsApp screenshots are also in `images/products/`.

## Preview

Open `index.html` in a browser. The page uses Google Fonts when an internet connection is available; the layout remains usable if they do not load.

## Add project photos later

Create an `images` folder beside `index.html`, then add:

- `hero-electrical.jpg` — wide hero image (landscape, ideally 1800 × 1200 or larger)
- `team-electrical.jpg` — team or project image (portrait or square)

The image paths are already wired into `styles.css`. The small “photo coming soon” notes can then be removed from `index.html`.
