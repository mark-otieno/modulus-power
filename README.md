# Modulus Power website shell

A responsive, single-page website starter for **Modulus Power and Electrical Controls Limited**. It presents electrical installation, domestic wiring, metering, maintenance and related electrical services. It does not advertise consumer electronics repair or sales.

## Preview

Open `index.html` in a browser. The page uses Google Fonts when an internet connection is available; the layout remains usable if they do not load.

## Add project photos later

Create an `images` folder beside `index.html`, then add:

- `hero-electrical.jpg` — wide hero image (landscape, ideally 1800 × 1200 or larger)
- `team-electrical.jpg` — team or project image (portrait or square)

The image paths are already wired into `styles.css`. The small “photo coming soon” notes can then be removed from `index.html`.
